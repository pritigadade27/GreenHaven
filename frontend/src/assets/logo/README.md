# Logo files

Two variants, each as SVG and PNG.

| File | Contains | Use it for |
|---|---|---|
| `green-haven-logo-with-name.*` | Emblem + "Green Haven" + tagline | Anywhere the brand is not already named: invoices, email headers, packaging, social profiles, presentations |
| `green-haven-logo-without-name.*` | Emblem only | Where the name already appears beside it, or where the space is too small to read text: favicons, app icons, watermarks, the site navbar |

**Prefer the SVG.** It is vector, so it stays sharp at any size and is a fraction
of the file size. The PNGs are there for tools that cannot place an SVG — most
print shops, some social platforms.

The site's navbar uses the *without-name* mark and sets the name as live text
beside it, so the wordmark stays selectable, translatable and crisp at every
screen density.

The wordmark is live text in these files. **Convert it to outlines before
sending anything to print** — a printer without the font installed will
substitute something else.
